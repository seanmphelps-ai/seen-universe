# Identification — extraction — emergence

Same template on every portal, every modality, all 64.
The asks do not change. The answers do.

## Asks (fixed)

1. What is the pressure point?
2. Where can I find myself here?
3. How would I show up?
4. In what location, with whom, does this come forward?

## Law

Every portal is live somewhere.
Every archetype turns on at some point.
None of them are a personality brand.

Activation is conditional:
- this soil
- this calendar
- this clock
- this person or group in the field

A family trip can wake one portal. A business trip can wake another. A pairing that works in one city can fail in the next. That is soil, not a new seed.

## Order

Native seed first. Untouched.
Then the four asks against that seed in this soil.
If two portals return the same sentence, the extraction failed.
