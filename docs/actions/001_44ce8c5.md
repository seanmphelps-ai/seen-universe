## Intake
Current repo file being read under the Oracle entry sequence.

## Input
The visible current file only.

## Action
Enter Oracle, read in order, see one file at a time, produce checkpoint, unlock next file, do not drift, do not preview future files.

## Output
A checkpoint stating:
- what the file is
- what job it performs
- what it governs
- what it must not govern
- what comes next
- whether drift, contradiction, missing dependency, or execution risk appears

## Runtime obligation
Block partial-context action, scattered search behavior, future-file guessing, and implementation from partial repo context.

## Status
Materialized from commit on `mirrored`.

## User-facing vs backstage
Backstage governance / repo actor gate.

## Enforcement target
LLMs, AI generators, repo actors, automation agents, and human contributors.
