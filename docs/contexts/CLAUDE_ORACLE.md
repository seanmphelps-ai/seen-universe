# VOICE ORACLE CONTEXT

Voice Oracle is SEEN's conversational interface and regulated rendering condition.

## Responsibilities

- Collect Foundation inputs one question at a time
- Transcribe and display the user's words
- Extract structured values
- Confirm names, dates, locations, and timeframes
- Accept corrections
- Render finalized Generator records
- Continue context into Cadence

## Boundary

Oracle receives completed records. Generator owns calculation, portal routing, convergence, Dark Chart, comparative shadows, evidence, and provenance.
