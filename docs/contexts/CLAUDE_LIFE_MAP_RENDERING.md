# LIFE MAP / RENDERING CONTEXT

The Life Map makes SEEN's structure visible without exposing proprietary implementation internals. Rendering changes presentation, not findings.

## Life Map

- Center the permanent 64-portal lattice/field.
- Keep every approved source system visually and structurally independent.
- Represent Forge/environment/exposure as contextual pressure around the pattern.
- Represent timing, relationships, events, wounds, and recurrence as activation/pressure layers.
- Show convergence only where independent supported signals meet.
- Allow zoom/drill-down from overview -> convergence -> portal -> source calculation/evidence.
- Life Sections sit on the human-readable perimeter after the final registry is locked.

## Public / private boundary

Public:
- source-system identity
- high-level origin/provenance
- visible portal/convergence relationships
- user-facing evidence explanation
- claim/evidence inspection

Private/server-side:
- proprietary weights
- hidden mapping tables
- scoring formulas
- prompts
- internal routing rules
- hidden schemas and implementation details not required for user inspection

## Source-system views

Each approved source system receives its own native view/tab. A system view uses the preserved raw source result and does not blend in other systems. Convergence is a separate view.

## Historical provenance

A source-system view/map marker may show tradition, origin region, earliest documented era, later development, and what the system contributes. Every production historical claim must carry verified source references. Approximate conversational dates are not production facts.

## Rendering modes

All render modes receive the same immutable supported Generator claim set.

Candidate modes:
- direct analytic
- narrative / memoir
- cinematic screenplay
- documentary / elder-storyteller
- landscape / natural-force metaphor
- evidence-map explanation

Every output preserves `renderMode`, `renderVersion`, `claimRefs`, and `evidenceRefs`.

Rendering may change voice, sequence, metaphor, scene construction, pacing, and emphasis. It cannot invent biography, alter source calculations, erase contradictions, or turn metaphor into evidence.

Rule: `Creativity after convergence, not before.`

## Visual standard

- Forge remains a continuous visual world rather than an isolated placard.
- Dark celestial / bronze-gold / ivory remains the working visual direction until the design system is explicitly changed.
- Typography is structural: width, scale, spacing, negative space, proportion, and motion are intentional system behaviors.
- Establish at least one ownable SEEN typographic/visual behavior that remains recognizable without celestial artwork.
- Mobile-first validation at 390–430 px is required.

## Western exploration

Western may use reel/carousel exploration and visual metaphors for houses so long as the UI remains a projection of the preserved Western calculation. Visual metaphor never changes native Western semantics.
