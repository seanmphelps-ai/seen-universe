# 00_FULL_REPO_READING_GATE

Before any SEEN structural change, review the full repository file by file.

Read `README_CORE_SCHEMA_ORDER.md` first.

Then read each listed file in that order.

Then review remaining files by folder and filename.

Before writing, reread the target file and adjacent ordered files.

If a current file is missing from the order list, update the order list before treating the repository as complete.

Applies to docs, schemas, runtime, governance, phase-zero, phase-one, GitHub workflow files, and `README_CORE_SCHEMA_ORDER.md`.
