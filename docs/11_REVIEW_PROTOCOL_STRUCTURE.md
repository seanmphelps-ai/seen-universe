# 11_REVIEW_PROTOCOL_STRUCTURE

Purpose: verify SEEN repository order, naming, numbering, folder placement, dependency order, and reference integrity.

This protocol runs after FOUNDATION and before ALIGNMENT.

No architecture may be invented in this protocol.

## PASS 6 - Naming

Check file names, exported names, headings, and references.

Flag:

- duplicate first files
- confusing roots
- wrong extensions
- misleading names
- names that imply the wrong read order
- names that collapse separate ontology layers

## PASS 7 - Numbering

Check numeric order.

Verify that earlier files are truly earlier in responsibility.

Do not preserve prior numbering blindly.

Preserve prior numbering only when it is structurally stronger.

## PASS 8 - Folder Placement

Check that each file sits in the correct directory:

- docs
- phase-zero
- governance
- runtime
- schemas
- scoring
- validation

Flag files that sit in the wrong conceptual layer.

## PASS 9 - Dependency Order

Check read/load order.

Required order:

1. transfer context
2. Oracle origin
3. Oracle discovery
4. Oracle depth/chips
5. canon
6. copilot rule
7. review protocol docs
8. review protocol schemas
9. governance
10. executable Oracle behavior schema
11. MVP flow
12. Cadence/sharing guardrails
13. runtime
14. schemas
15. scoring
16. validation
17. recovery/fallback

## PASS 10 - Reference Integrity

Check imports, links, mentions, read-order references, protocol references, and file-name references.

Flag references to missing files.

Flag references to superseded names.

Flag references that would make future models read files in the wrong order.

## Gate Output

Return:

1. Naming findings
2. Numbering findings
3. Folder placement findings
4. Dependency order findings
5. Reference integrity findings
6. Exact files requiring move or rename
7. Confidence per finding: locked / likely / uncertain

Do not apply changes in this protocol.
