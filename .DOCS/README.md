# SEEN DOCUMENT CONTROL

This directory is the modular working memory for SEEN.

## Loading rule

1. Read the root `CLAUDE.md`.
2. Read `.DOCS/MASTER_BUILD_CHECKLIST.md` for status and build order.
3. Load only the context file that matches the current task.
4. Load exemplars only when evaluating or generating the same output type.

## Authority order

1. Sean's latest explicit correction
2. Locked canonical contract
3. Runtime schema and tests
4. Approved exemplar
5. Implementation copy
