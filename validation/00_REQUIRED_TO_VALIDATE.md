# REQUIRED TO VALIDATE

Traditional scoring stays intact.
Biome / GeoPresence becomes a primary modifier layer.

A scientist would require:

- repeatable measurable correlations
- birth data time ranges
- planetary + house positions
- birth location
- environmental dataset
- life outcomes

Biome variables:

- elevation
- temperature variance
- humidity
- sunlight hours
- population density
- distance to water
- vegetation density
- predator proxy
- urbanization index

Generator requirements:

Everything must be:

- defined
- measurable
- repeatable
- encoded

Pipeline:

1. Generate sources independently
2. Score each element
3. Apply biome modifier
4. Route into portals
5. Output observable behavior + failure modes + cost if unregulated
